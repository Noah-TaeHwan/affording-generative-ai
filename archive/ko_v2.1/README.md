# Korean edition of version 2.1 (archived)

`Affording_Generative_AI_KO_v2.1.pdf` (39 pages) and its LaTeX source `main.tex` are the Korean edition of version 2.1 of the paper
(8 October 2026), deposited on Zenodo with version 2.1 of the replication package (https://doi.org/10.5281/zenodo.23240879).
It translates the version 2.1 English text and does not include the changes of version 3.1. A Korean edition of version 3.1 does not exist yet.
